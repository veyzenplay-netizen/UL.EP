Lesson 1

                            
What is a pixel?

                            
A digital picture is a grid of tiny squares called pixels. Each square holds just one colour. From far away your eyes blend them into a smooth image. Fewer pixels means bigger squares and less detail.

                            

                                
                                

                                    
                                    
                                    
Drag the slider. At 4 you only see blocks. At 80 it looks smooth. That count is the image's resolution.

                                

                            

                            
Key idea: total pixels = width × height.

                            

                                
                                
                            

                        


                        

                            
Lesson 2

                            
Colour is three numbers

                            
Every pixel stores how much red, green and blue light to show, each from 0 to 255. The computer keeps those numbers in binary.

                            

                                

                                

                                    

                                        
                                        
                                        
                                        
                                        
                                        
                                    

                                    

                                

                            

                            
Key idea: 3 numbers × 8 bits each = 24 bits for one colour pixel.

Lesson 4

                            
File formats and compression

                            
Raw picture data is huge, so files are compressed. Lossy formats throw away detail you barely notice. Lossless formats shrink the file but can restore every pixel.

                            

                                

                                    
FormatCompressionTransparencyBest for

Key idea: lower quality means a smaller file but more visible artifacts.

                            

                                
                                
                            

                        


                        

                            
Lesson 5

                            
Resizing and aspect ratio

                            
Aspect ratio is the shape of a picture. If you change the width, the height must change by the same factor, or the picture looks stretched.
